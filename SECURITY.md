## Reporting a Vulnerability

The Git History & Metadata Rewriter handles cryptographic commit structures. If you identify a potential defect, memory leak, or security exposure in the execution pipeline:

1. **Do not disclose publicly via GitHub Issues.**
2. Send an encrypted or confidential report directly to:
   - **Lead Architect**: Shardendu Mishra
   - **Email**: mishrashardendu22@gmail.com
3. Please include reproduction steps, environment details, and attack vector analysis.

All vulnerability submissions will receive an acknowledgment within 24 hours.
